# Internet Systems Consortium (ISC)

> **Type**: Organization
> **Role**: Maintainer of BIND 9, the reference DNS server implementation

---

## Description

ISC is the nonprofit organization that develops and maintains **BIND 9** (Berkeley Internet Name Domain), the most widely deployed DNS server software and the reference implementation for DNS and DNSSEC standards. ISC also maintains the DNS-related software `Kea` (DHCP) and publishes authoritative DNSSEC operational guidance.

ISC is the primary institutional voice on DNSSEC implementation in BIND. Their KASP (`dnssec-policy`) feature, introduced in BIND 9.16, represents the current standard for automated key management.
